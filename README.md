# 小日账

面向 iPhone 的本地个人账本，支持手动记账、两级分类、JPY/CNY 汇总、CSV 和 Excel 导入、离线使用及 JSON 备份。

## 本地预览

在项目目录运行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist`，打开 [本机预览](http://127.0.0.1:8765/)。

## iPhone 使用

在 Safari 打开私有部署链接并登录。选择「分享」→「添加到主屏幕」，开启「作为 Web App 打开」，再从主屏幕打开一次并等待离线应用就绪。正式流水从主屏幕录入，账本和导入文件都在浏览器内处理。「设置与备份」可以导出完整账本到「文件」，或从 JSON 恢复。

### 轻点背面记账

1. 在「快捷指令」新建「小日账·屏幕记账」，依次添加「截屏」「从图像提取文本」「拷贝至剪贴板」「前往主屏幕」。中间两步各自使用上一步的结果。
2. 在「设置」→「辅助功能」→「触控」→「轻点背面」→「轻点两下」选择这个快捷指令。
3. 在付款或收款详情页轻点背面两下，手机回到主屏幕后打开小日账，点底部弹出的「粘贴屏幕账单」，再点系统的「粘贴」。顶部的扫描图标也能随时粘贴；读不到剪贴板时会改为手动粘贴。
4. 金额、币种、时间和商户自动预填。同一商户沿用上次的分类，常见店铺（便利店、咖啡、交通卡等）按关键词自动选分类；金额和时间与已有流水接近时会提示可能重复。核对后保存。

截屏与文字识别在 iPhone 上进行。小日账在本机解析粘贴的文字，只保存确认时填写的流水字段。iOS 目前没有可靠的办法让快捷指令把文字直接交给主屏幕上的网页 App，所以仍需要轻点一次「粘贴」。

## 开发

应用源码直接放在 `dist/`，可作为静态站点部署，不需要额外构建。推送到 `main` 后，GitHub Actions 会把 `dist/` 发布到 [GitHub Pages](https://silverbullet522.github.io/xiaorizhang/)。发布静态资源变更时同步更新 `dist/sw.js` 的缓存版本和资源清单。汇率使用 Frankfurter v2，Excel 由随应用分发的 SheetJS 解析。运行 `node --test` 验证日期、金额、换算、导入和统计逻辑。
